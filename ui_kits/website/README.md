# Podzi.ai — Marketing Website UI Kit

Single-page recreation of the Podzi.ai marketing site, built on the design-system tokens, logo, and patterns.

## Sections
Sticky glass nav · hero (headline + animated player card + store badges) · trust strip · "How it works" 3-step · feature grid (6) · dark stat band over the waveform pattern · CTA · footer.

## Run
Open `index.html`. Pure HTML/CSS with a few lines of vanilla JS (hero waveform generation + cosmetic play toggle). Links `../../styles.css`.

## Notes
- Store badges are inline SVG placeholders.
- Designed at ~1180px content width; scale the frame for other breakpoints.
