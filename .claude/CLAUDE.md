# gstack

Use the `/browse` skill from gstack for all web browsing. Never use `mcp__Claude_in_Chrome__*` tools.

## Available gstack skills

- `/office-hours` — YC-style forcing questions or design thinking brainstorm
- `/plan-ceo-review` — CEO/founder-mode plan review
- `/plan-eng-review` — Eng manager-mode plan review
- `/plan-design-review` — Designer's eye plan review
- `/design-consultation` — Full design system proposal, creates DESIGN.md
- `/review` — Pre-landing PR review
- `/ship` — Ship workflow: merge, test, bump version, create PR
- `/browse` — Fast headless browser for web browsing and QA
- `/qa` — Systematically QA test a web app and fix bugs
- `/qa-only` — QA report only, no fixes
- `/design-review` — Visual QA: find and fix spacing/hierarchy issues
- `/setup-browser-cookies` — Import real browser cookies into headless session
- `/retro` — Weekly engineering retrospective
- `/debug` — Systematic root-cause debugging
- `/document-release` — Post-ship documentation update
